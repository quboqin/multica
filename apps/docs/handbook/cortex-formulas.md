# 集合公式字段

公式是集合专属的只读字段：整列共用一个表达式，对每一行分别计算。网页、桌面端和 CLI 使用服务端返回的相同结果。任务自定义字段不增加公式类型。

## 使用

在表头点击 `+` → 字段类型选“公式” → 填写名称和表达式 → 创建字段。已有公式通过列菜单“编辑字段”修改。

```text
{数量} * {单价}
ROUND({金额} * {比例}, 2)
IF({状态} == "完成", "通过", "待处理")
IFERROR({金额} / {数量}, 0)
CONCAT({title}, " / ", {分类})
```

- `{字段名}` 引用同表字段；也可使用 `{字段 UUID}`。`{title}` 固定表示首列标题。
- 引用绑定到字段 ID；源字段改名后仍计算原字段，重新打开编辑器会显示最新字段名。
- 支持引用文本、数字、日期、URL、复选框、单选和其他公式。单选以选项名称参与计算；日期以 `YYYY-MM-DD` 文本参与计算。人员、多选和关联字段暂不能作为输入。
- 字段名里的 `}` 和反斜杠用反斜杠转义；点击插入字段会自动处理。
- 文本使用双引号，布尔值使用 `TRUE` / `FALSE`，空值使用 `NULL`。开头的 `=` 可省略。
- 空值在数字运算中按 `0` 处理，在文本拼接中按空字符串处理。文本数字需要显式使用 `VALUE()` 转换。
- 公式结果为数字、文本、布尔值或空值。数值采用浮点计算；金额等需要确定小数位时使用 `ROUND()`。

## 运算符与函数

| 类别 | 支持内容 |
| --- | --- |
| 数值 | `+ - * / %`、括号、一元正负号 |
| 比较 | `== != > >= < <=` |
| 逻辑 | `&& \|\| !`、`AND`、`OR`、`NOT` |
| 条件与空值 | `IF(condition, yes, no)`、`IFERROR(value, fallback)`、`ISBLANK(value)`、`COALESCE(...)` |
| 同行多值计算 | `SUM(...)`、`AVG(...)`、`MIN(...)`、`MAX(...)` |
| 数字处理 | `ROUND(value[, digits])`、`ABS`、`CEIL`、`FLOOR`、`VALUE` |
| 文本 | `CONCAT(...)`、`LEN`、`LOWER`、`UPPER`、`TRIM` |

`ROUND` 小数位范围是 -10 到 10。`IF`、`IFERROR`、逻辑与空值函数按需计算分支。`LEN` 计算 Unicode 字符数。

## 错误与数据一致性

保存前校验表达式、函数参数、引用范围和循环依赖。无效表达式不能覆盖现有公式，编辑输入保留。

| 单元格错误 | 含义 |
| --- | --- |
| `#REF!` | 依赖字段已归档、缺失或类型不再受支持；恢复字段后重新计算 |
| `#DIV/0!` | 除零或对零取余 |
| `#VALUE!` | 输入类型不匹配或结果文本超出限制 |
| `#NUM!` | 数值溢出或舍入参数不合法 |

结果在读取记录时计算，不写回 `record.fields`。单格写入、清空、建行、批量更新和 CSV 追加都拒绝向公式字段写值；CSV 模板与批量字段选择器省略公式字段。源数据更新、批量修改、字段修改、归档恢复后，下次读取返回重新计算的结果。

表达式最多 4096 字节、256 个语法节点、32 层语法嵌套；输出文本最多 8192 字节。解释器只处理允许的表达式，不执行用户代码，不访问网络或文件。

## CLI

```bash
multica collection field add "订单" --name "总价" --type formula --expression '{数量} * {单价}'
multica collection field update "订单" "总价" --expression 'ROUND({数量} * {单价}, 2)'
multica record list "订单" --output json
```

已有集合字段管理权限同样适用于公式。智能体按运行时主人的权限管理字段，并从普通记录查询中读取计算结果。

## 当前边界

这是同一行的公式计算，不包含跨行/跨表 rollup、Excel 单元格坐标或完整 Excel 函数兼容。Excel 导入仍读取已保存的单元格值，不把工作簿公式翻译成集合公式。

公式字段暂不支持排序、筛选、分组或作为日历日期字段；界面不展示这些操作，直接 API 查询会明确拒绝。公式可作为表格、看板、画廊、行详情与文档内嵌视图的展示字段。

## 本地验收

1. 用 `make up` 启动当前检出目录的环境；若 API 已启动，先 `make down ARGS='--components api'` 再启动以加载代码。迁移 516 增加公式字段类型。
2. 创建数字字段“数量”“单价”，填入 `3` 和 `12.5`；创建“总价”公式 `{数量} * {单价}`，应显示 `37.5`。
3. 数量改为 `4`，总价应更新为 `50`，刷新仍为 `50`。
4. 创建“含税”公式 `ROUND({总价} * 1.1, 2)`，应显示 `55`。
5. 将“单价”改名为“售价”，结果不变，打开公式编辑器可看到更新后的引用。
6. 将总价改为 `{含税} + 1`，应拒绝循环引用并保留输入；取消后原公式仍生效。
7. 将总价改为 `{数量} / 0`，应显示 `#DIV/0!`；改为 `IFERROR({数量} / 0, 0)` 后显示 `0`。
8. 归档被引用字段，依赖结果显示 `#REF!`；恢复字段后恢复计算。
