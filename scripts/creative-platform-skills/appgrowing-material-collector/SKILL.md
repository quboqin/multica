# AppGrowing 素材采集

读取 `references/appgrowing-collection-contract.md` 并严格执行。先在子 Issue 用自然语言确认理解，
再运行真实采集。结果必须写入创意批次父 Issue 的原生候选池；子 Issue 只保留执行证据、命中统计
和失败原因。

不得生成替代素材、额外看板或内部调试信息。授权失效时只说明平台重新绑定入口。
