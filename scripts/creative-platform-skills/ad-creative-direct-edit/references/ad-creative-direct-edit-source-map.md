| --- | --- |
| A native direct task carries the order, variant, revision, and task-owned `expected_sizes` context | `server/internal/service/task.go:EnqueueDirectTaskFanout`, `server/internal/handler/creative_direct_edit.go:CreateCreativeDirectEdit` |

| `multica image edit-batch` applies the same provider slot limiter and returns the exact prompt/hash for each job | `server/cmd/multica/cmd_image_batch.go:imageEditBatchResult`, `server/cmd/multica/cmd_image_batch.go:executeImageEditBatch` |
| Annotated size adjustments upload a same-size raster guide; source base is Input 1 and the guide is Input 2, while numbered red marks remain out of the output | `packages/views/creative/components/creative-studio-page.tsx:createAnnotationGuideAttachment`, `server/internal/handler/creative_order_adjustment.go:QueueCreativeOrderAdjustment`, `server/internal/handler/task_fanout.go:validateCreativeDirectEditTaskContext` |
| Direct-edit prompts are short executable edit prompts; they do not duplicate order audit prose and still preserve the exact provider prompt/hash returned by the image CLI | `scripts/creative-platform-skills/ad-creative-direct-edit/SKILL.md:广告图片直接修改`, `server/cmd/multica/cmd_creative.go:imagePromptSHA256` |

| `multica creative order asset-put` records the generated base and lineage, validates its prompt trace, and rejects a different overwrite after completion | `server/cmd/multica/cmd_creative_domain.go:runCreativeOrderAssetPut`, `server/internal/handler/creative_domain.go:normalizeCreativeOrderAsset`, `server/internal/handler/creative_domain.go:validateCompletedGeneratedAssetTrace`, `server/internal/handler/creative_domain.go:UpsertCreativeOrderAsset` |
| Diagnostic asset task ownership is checked against the current creative order context; direct-edit diagnostic task linkage is optional after an ownership repair attempt | `server/internal/handler/creative_domain.go:UpsertCreativeOrderDiagnosticAsset`, `server/internal/handler/creative_domain.go:normalizeCreativeOrderDiagnosticAsset` |
| Direct-edit generated bases are passed to the deterministic Prime composer, copied to delivered assets, and skip QC; every model attempt remains a diagnostic asset even when rejected | `server/internal/handler/creative_prime_backend.go:composeCreativeOrderVariantPrime`, `server/internal/handler/creative_domain.go:copyCreativePrimedAssetsToDelivered`, `server/internal/handler/creative_domain.go:UpsertCreativeOrderDiagnosticAsset` |
| Human direct-edit initialization fixes the source asset at revision 1 and records candidate, request, size, delivery mode, squad, and leader trace | `server/internal/handler/creative_direct_edit.go:CreateCreativeDirectEdit` |
| Active direct tasks are idempotent by target agent, evidence pair, and `item_key` rather than by source alone | `server/internal/service/task.go:EnqueueDirectTaskFanout`, `server/internal/service/task.go:directTaskItemKey` |
