# 投放素材工作流使用说明

## 目标

从 AppGrowing 候选池中选择一张竞品参考图，自动生成 AdaKami 本地化投放素材。服务会分析参考图的业务模块，从已确认的 Excel catalog 选择同职责文案，生成 3 个视觉变体，并为每个变体生成 3 个投放尺寸。

最终尺寸：

- `1080x1080`，尺寸码 `11`
- `800x1000`，尺寸码 `45`
- `1200x628`，尺寸码 `191`

## 业务使用

1. 在 Multica 打开带有“素材候选池”的任务。
2. 从候选池挑选一张或多张参考图，状态改为“已选中”。
3. 可选填写“给修图智能体的补充要求”。这里适合填写视觉偏好或需要保留的通用结构，不要手写金额、费率、期限或监管承诺。
4. 点击“交给修图智能体”。页面会在当前 Issue 中真实提及修图智能体；智能体读取已选素材后，经 MCP 创建异步修图任务。这样用户也可以在 Issue 对话中直接 @修图智能体提出同类请求。
5. 智能体创建的任务会自动回写到同一候选池下方的“修图结果看板”。在这里查看任务进度；点击“预览成图”进入大预览：左侧为原始参考图，右侧直接展示所有通过变体及各自三种尺寸；点击任一图片可查看原尺寸。
6. 展开“QC 每轮记录”查看每一次尝试图、失败原因、纠错结果和尺寸信息。未通过的图片也会保留，但不会混入最终交付。
7. 对每个通过变体提交“接受”“需要调整”或“不采用”，并填写具体原因。反馈会与该变体、文案选择和过程数据绑定，供后续优化使用。
8. 点击“全部下载”获取原始参考图、所有通过的最终成图和 `manifest.json`。下载包仅包含可交付成图；失败尝试仅在页面 QC 记录和过程报告中查看。

### 部分完成的处理

- 页面显示“已完成 N/3 变体”时，表示通过 QC 的变体可以正常预览、反馈和下载；未完成的变体及其每一轮失败图保留在“QC 每轮记录”。
- 不能因为一个变体失败而隐藏或阻断已经通过的三尺寸成图，也不能把失败变体混入下载包。
- 反馈应针对具体变体给出。若失败原因为未授权金额、品牌框架错误或非目标比例，应修改生成约束后重新发起任务，而不是人工放行。

## 文案与品牌规则

- 业务文案来自 market profile 绑定的已确认 Excel catalog。参考图只提供结构和模块职责，不是金额、费率、期限或 CTA 的真值来源。
- 同一参考图的 3 个变体使用同一套已授权业务文案，确保可以公平比较视觉方案；视觉层面必须分别采用 Offer-led、App-led、Lifestyle-led 构图方向。
- AdaKami Logo、右上条款/QR、商店徽章、OJK、AFPI、PINDAR 和底部合规区由对应尺寸的 Prime 模板作为模型输入。
- 品牌四角或页脚资产有缺失、错画、替换、重复或位置错误时，QC 必须失败。系统不进行最终 Logo、二维码或页脚后贴。

## 文件命名

最终投放图统一使用：

`Month_P_Brand_Country_YYYYMMDD_PicType_Designer_Size.png`

例如：`07_P_AK_ID_20260716_NUM_AI02_45.png`。

无论上游文件 URL 是否保留原文件名，下载打包时都会按任务日期、市场、变体和尺寸码重建最终成图名称，不允许退回为 `1080x1080.png` 之类的尺寸名。原始参考图位于下载包的 `original/` 目录，不属于最终投放成图。

## 本地运行与部署

本地服务地址：

- Multica Web：`http://localhost:3001`
- Multica API：`http://127.0.0.1:18080`
- Lean 创意服务：`http://127.0.0.1:8010`
- Creative MCP：`http://127.0.0.1:19518/mcp`

Multica 后端必须配置以下环境变量：

- `MULTICA_WORKSPACE_MCP_KEY`：base64 编码的 32 字节密钥，用于加密工作区 MCP 鉴权头。
- `MULTICA_WORKSPACE_MCP_ALLOWED_HOSTS`：Creative MCP 的受控域名。本地使用 `127.0.0.1`。
- `MULTICA_CREATIVE_ARCHIVE_ALLOWED_HOSTS`：可打包下载的成图域名。本地 Lean 使用 `127.0.0.1`。

Creative MCP 必须配置 `CREATIVE_MCP_AUTH_TOKEN`，并在 Multica 的工作区 MCP 连接中以 `Authorization: Bearer ...` 写入相同值。不要把密钥、token、Cookie 或签名 URL 写入文档、Issue、报告或前端。

生产环境应将两个 allowed-hosts 变量配置为受控的 MCP 和素材域名，不能泛化为任意内网地址。

Lean 创意服务还应配置：

- `LEAN_IMAGE_REQUEST_TIMEOUT_SECONDS=600`：单次图像请求最多等待 10 分钟；超时或网关断连会在 QC 过程记录中落为失败，不会让任务无限显示“运行中”。
- 如果自有图像网关是内网域名，必须将该域名加入 `NO_PROXY`。否则本机 HTTP(S) 代理可能将内网请求错误转发，表现为请求长期无返回。
- 重启 Web 服务后才会加载跨包视图组件的代码更新；部署时应以新 bundle 启动，不能只重启 API。

## 验收标准

- 每张选中参考图请求 3 个变体，每个通过变体有 3 个尺寸。
- 每个尺寸使用对应的 Prime 模板：方图 `11-01`、竖图 `45-01`、横图 `191-01`。
- 结果页、下载包和 `manifest.json` 中的变体数量一致。
- QC 失败图、失败原因和生成过程可追溯；可交付结果与失败尝试清晰分离。
- 用户反馈能在对应变体下回看，并保留当时的文案选择和过程快照。
