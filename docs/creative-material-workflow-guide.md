# 投放素材协作使用说明

## 平台配置

“创意工厂”只维护三类业务资源：

1. 素材库：查看 AppGrowing 归档素材，或从本地文件、URL 人工导入；支持搜索、竞品筛选、详情预览和下载。
2. 文案库：维护已审核的投放文案、通用卖点和还款计划预设；在线新增、修改和发布。文案不再通过 Excel 模板导入。
3. 市场资源包：维护市场、语言、货币、二维码、合规和命名规则，绑定文案库，并动态添加图片、文档等资源文件。

资源文件的“用途”可以自定义，同一用途可以有多条。AdaKami Indonesia 当前包含三个 Prime
完整模板、品牌规范和 `app_ui_reference`。App UI 参考图可持续追加；当候选图包含竞品 App
界面时，分析智能体从全部参考图中选择最匹配的一张或多张，后续模型用真实 AdaKami 界面替换
竞品界面。

智能体的工作方法通过平台普通 Skill 维护，并绑定到对应智能体。小队 Leader 读取实时小队名册、
成员职责和 Skill 动态委派；平台不提供任务模板、固定节点或展开方式配置。

## 从采集到修图

1. 用户在素材库中点击“立即运行”。Autopilot 创建一个 Crawl Run，并把真实采集结果写入工作区素材库。
2. 采集完成后，系统只为本次新增的图片自动创建参考分析 task；视频等非图片素材保留在本次结果中，但不计入图片分析进度。
3. 用户直接在“本次运行素材”中查看新增素材和分析状态。分析完成的图片可以直接选择；选择记录与完整素材库共用，随后页面自动定位到该素材的逐块文案配置。
4. 模型根据原图逐块文字、版式和已发布文案库完成文字填充。用户可以直接改每个位置的文字，或保留为空；为空时生产提示词会移除竞品原文，不会臆造未审核内容。
5. 用户固定已发布市场资源包和执行小队，点击“开始修图”。平台为每张图创建独立创意工作 Issue。
6. Leader 根据当前证据和成员能力，一次委派所有已就绪任务：先并发 V01-V03 三个方形母版，
   再以各自母版为第一参考并发原生重排横版和竖版。
7. 每个创意独立完成三尺寸 Prime 包装和 QC。Leader 只在 3 个创意 × 3 个尺寸全部通过后发布。
8. 结果看板按创意展示原图对比；可放大为接近全屏的工作台继续切换创意和尺寸，也可下载单尺寸、
   当前创意 ZIP 或全批次 ZIP。
9. 用户点击“调整当前创意”提交精确反馈，只返工目标创意中的当前尺寸或整组三尺寸。

每次采集、分析、文案适配和生产都有独立的结构化记录。业务页面展示本次结果、选择、文案配置和
交付结论；底层 task 保留输入、输出和失败证据。

## 本次采集与分析

点击“立即运行”后，页面会自动打开“本次运行素材”。这个区域只显示当前 Crawl Run 的新增素材，不会
把历史复用素材混入本次结果。关闭后可通过“查看本次素材”再次打开。

图片的状态按实际分析 task 派生：

| 页面状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| 分析排队中 | 图片已入库，尚未被分析 task 执行 | 等待执行 |
| 分析中 | 分析智能体正在读取图片 | 等待完成 |
| 已完成分析 | 已有可用的 Source Analysis | 直接选择素材 |
| 分析失败 | 本次分析 task 失败 | 从素材卡重新发起分析 |

“本次新增”同时展示图片和非图片数量。只有图片进入参考分析计数，因此不能用总入库数判断图片分析
是否卡住。每个完成分析的图片卡都有“选择素材”；选择后不需要再到下方完整素材库重复选择，页面会
定位到同一条素材的逐块文字填充。

采集智能体提交分析 fanout 前会校验当前运行时 CLI 是否支持 `multica task fanout`。如果出现
`multica task fanout unavailable; upgrade CLI`，表示采集结果已保留，但尚未开始自动分析；应升级
当前守护进程使用的 CLI 后重新运行该 Crawl Run 的预分析，而不是把“采集完成”当成“分析完成”。

## 逐块文案适配

参考分析识别原图中每一个文字区块的位置、角色和原文。文案适配模型在已发布文案库、还款计划预设和
市场资源包之间选择可用内容，输出“原图文字 -> 我方替换文字”的可编辑生产输入。

- 还款金额、期限和月供按已发布还款计划预设选择或重排，不复用竞品数值。
- 通用卖点只用于原图中确有空位且语义适合的文字区块，不能用品牌名或未经审核的金融承诺硬填。
- 找不到合适的已审核文案时，用户可以保留该区块为空；生产会删除原竞品文字，不翻译、不保留，也不补造内容。
- 逐块文案是方案设计的共同输入。后续三个变体可以改变视觉构图和强调重点，但不得绕过已确认的核心文案与事实。

## 当前市场

当前运行范围只有 Indonesia，语言为 Indonesian，市场包为 `AdaKami Indonesia 市场资源包`。
未来增加其他市场时，在页面创建或复制市场资源
包、绑定当地文案库并上传当地文件；通用 Skill 按新市场快照执行，不需要修改应用代码。

## Prime 与工具

- 最终尺寸为 `1080x1080`、`1200x628` 和 `800x1000`。
- 每张入选参考素材固定交付 V01-V03 三个创意，每个创意包含上述三个尺寸，共九张图。
- 三个 Prime PNG 是完整贴图，必须从 Issue 固定的市场包版本读取。
- 不新增二维码白底，不移动或折叠条款区域。
- 确定性合成脚本属于 `Prime 完整贴图` Skill 的 reference，不属于市场资源文件。
- 质检记录实际像素、二维码解码、品牌与条款可见性、文案一致性和文件名。

## AppGrowing 授权

AppGrowing 登录态在“设置 - 集成”中绑定。Issue、评论和 Skill 不保存账号、密码、验证码、
Cookie 或 Token。授权失效时重新绑定后再执行真实采集，不用测试素材替代。

## 成图调整

结果看板中的每个创意都保留竞品原图对比。点击“调整当前创意”后，可以边看原图和当前成图边
填写要求：

- 只改当前尺寸时，选择“仅当前尺寸”；系统只重做这一张。
- 同一创意的三个尺寸都存在相同问题时，选择“当前创意三尺寸”；系统会分别处理三个原生尺寸。
- 需要改变主题、主利益点或整套文案时，应回到候选池修改该素材的创意输入，再启动新修订。

每次调整都会创建新的子 Issue，Leader、图像编辑、Prime 和 QC 的详细过程仍只在子 Issue 中。
父 Issue 结果看板默认展示每个尺寸的最新修订，历史成图不会被覆盖，可继续追溯和下载。
