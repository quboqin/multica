# 投放素材协作使用说明

## 平台配置

“创意工厂”只维护三类业务资源：

1. 素材库：查看 AppGrowing 归档素材，或从本地文件、URL 人工导入；支持搜索、竞品筛选、详情预览和下载。
2. 文案库：导入 Excel，在线新增、修改和审核文案。
3. 市场资源包：维护市场、语言、货币、二维码、合规和命名规则，绑定文案库，并动态添加图片、文档等资源文件。

资源文件的“用途”可以自定义，同一用途可以有多条。AdaKami Indonesia 当前包含三个 Prime
完整模板、品牌规范和 `app_ui_reference`。App UI 参考图可持续追加；当候选图包含竞品 App
界面时，分析智能体从全部参考图中选择最匹配的一张或多张，后续模型用真实 AdaKami 界面替换
竞品界面。

智能体的工作方法通过平台普通 Skill 维护，并绑定到对应智能体。小队 Leader 读取实时小队名册、
成员职责和 Skill 动态委派；平台不提供任务模板、固定节点或展开方式配置。

## 从采集到修图

1. Autopilot 按计划创建创意批次父 Issue，并分配给素材小队。
2. Leader 委派 AppGrowing 采集智能体，真实结果写入父 Issue 原生候选池；采集证据留在子 Issue。
3. 用户选择一张或多张参考图。每张图分别选择文案库记录，或在线精确编辑本图文案。
4. 用户固定已发布市场资源包和执行小队，点击“开始修图”。平台为每张图创建独立创意工作 Issue。
5. Leader 根据当前证据和成员能力，一次委派所有已就绪任务：先并发 V01-V03 三个方形母版，
   再以各自母版为第一参考并发原生重排横版和竖版。
6. 每个创意独立完成三尺寸 Prime 包装和 QC。Leader 只在 3 个创意 × 3 个尺寸全部通过后发布。
7. 结果看板按创意展示原图对比，可下载单尺寸、当前创意 ZIP 或全批次 ZIP。
8. 用户点击“调整当前创意”提交精确反馈，只返工目标创意中的当前尺寸或整组三尺寸。

父 Issue 只展示候选池、结果看板和必须让业务用户知道的结论。提示词、模型证据、包装和质检
讨论均保留在对应子 Issue。

## 当前市场

当前运行范围只有 Indonesia，语言为 Indonesian，市场包为 `AdaKami Indonesia 市场资源包`。
未来增加其他市场时，在页面创建或复制市场资源
包、绑定当地文案库并上传当地文件；通用 Skill 按新市场快照执行，不需要修改应用代码。

## Prime 与工具

- 最终尺寸为 `1080x1080`、`1200x628` 和 `800x1000`。
- 每张入选参考素材固定交付 V01-V03 三个创意，每个创意包含上述三个尺寸，共九张图。
- 三个 Prime PNG 是完整贴图，必须从 Issue 固定的市场包版本读取。
- 不新增二维码白底，不移动或折叠条款区域。
- 确定性合成脚本属于 `Prime 完整贴图` Skill 的 reference，不属于市场资源文件。
- 质检记录实际像素、二维码解码、品牌与条款可见性、文案一致性和文件名。

## AppGrowing 授权

AppGrowing 登录态在“设置 - 集成”中绑定。Issue、评论和 Skill 不保存账号、密码、验证码、
Cookie 或 Token。授权失效时重新绑定后再执行真实采集，不用测试素材替代。
